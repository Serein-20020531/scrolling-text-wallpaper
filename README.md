# scrolling-text-wallpaper
A customizable red desktop wallpaper with vertically scrolling Chinese text.
## 使用方法

1. 打开网页：
   https://serein-20020531.github.io/scrolling-text-wallpaper/

2. 输入需要展示的滚动文字。

3. 设置滚动速度、文字大小和背景颜色。

4. 点击“应用并保存”。

5. 点击“复制壁纸链接”。

6. 打开 Lively Wallpaper。

7. 点击“+ Add Wallpaper”。

8. 选择通过网址添加，并粘贴复制的壁纸链接。

9. 将其设置为 Windows 动态桌面壁纸。

## 功能说明

- 支持自定义滚动文字
- 每行文字生成一列
- 支持调整滚动速度
- 支持调整文字大小
- 支持修改背景颜色
- 支持无缝循环滚动
- 支持全屏预览
- 支持生成壁纸专用链接


如何真正设置成动态壁纸

建议使用免费的 Lively Wallpaper。

操作顺序：

打开你的普通网页地址。
输入需要展示的文字。
点击“应用并保存”。
点击“复制壁纸链接”。
打开 Lively Wallpaper。
点击 + Add Wallpaper。
选择通过网址添加。
粘贴刚才复制的链接。
设为桌面壁纸。
